● I added an outdated column to the leaders table in database.py. It's true when
  a person's as_of date is more than 365 days before today.

  How it works:
  - A new function, is_outdated(as_of, today=None), reads the date formats the
    app stores (2025, 2025-04, 2025-04-25). A missing month or day counts as the
    1st, which matches the existing entities._is_stale rule.
  - The value is computed when a leader is saved.
  - Because "more than a year ago" changes as time passes, the stored value
    would go stale. So get_leaders() recalculates it for that company before
    returning rows, and init_db() recalculates it for every row.
  - get_leaders() returns outdated as a Python True/False. SQLite stores it as 0
    or 1.
  - Your existing leadership.db was created before this column existed.
    init_db() now adds the column if it's missing, so you don't need to delete
    the database.

  Decision for you: when a person has no as_of date at all, I set outdated to
  false, because there's no date to compare. If undated evidence should count as
  outdated, that's a one-line change in is_outdated.
