● That's expected. The VS Code extension comes with its own copy of Claude Code,
  and it doesn't add a claude command to your terminal's PATH. To use claude in
  PowerShell, install the CLI separately using either option below.

  Option 1: Native installer (recommended)

  Run this in PowerShell:

  irm https://claude.ai/install.ps1 | iex

  Option 2: npm (needs Node.js 18 or later)

  npm install -g @anthropic-ai/claude-code

  Then:
  1. Close and reopen your terminal. In VS Code, kill the terminal with the
     trash icon and open a new one, so it picks up the updated PATH.
  2. Run claude --version to confirm it worked.
  3. Run claude and sign in with the same account you use in the extension.

  If it still isn't found, the install folder probably isn't on your PATH:
  - Native install: add %USERPROFILE%\.local\bin to your user PATH.
  - npm install: run npm config get prefix and add the folder it prints, usually
    %APPDATA%\npm.

  You don't need the terminal command to use Claude Code inside VS Code. The
  extension panel you're using now works on its own. You only need the CLI if
  you want to run claude in a terminal.
